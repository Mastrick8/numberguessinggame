# Number Guessing Game 🎯

A simple Python number guessing game where the player chooses a difficulty level 
and tries to guess a randomly generated number.

## Features

- Three difficulty levels:
  - Easy: 1–10
  - Medium: 1–50
  - Hard: 1–100
- Random number generation
- Tracks the number of attempts
- Tells the player if their guess is too high or too low
- Allows the player to play again
- Handles different difficulty selections

## Technologies Used

- Python 3
- Random module

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run `main.py`.
